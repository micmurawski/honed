Improve this project's agent configuration in response to these reflections on sessions run in the project.

Change what the reflections show hurt the work, and protect what they show helped. Prefer tightening or
rewording an instruction to adding new ones; remove an instruction only when the reflections show it does
harm. Sessions may come from several harnesses, so do not tailor shared instructions to one of them. Do not
change the commands a skill or hook runs unless a reflection shows they are wrong.

Ratings may name a failure mode the cited lines contributed to (premature_done, no_verification, …). Where
several reflections name the same mode, prefer the change that would prevent it.

Each reflection says how it was made. One made by the session's own agent, in the session, judges the
instructions that agent just followed: where it disagrees with one made by a reviewer handed the session, give
the reviewer's more weight.
